# Тарелка — интерактивный прототип MVP

## Как открыть
1. Распакуйте архив.
2. Откройте `index.html` в современном браузере.
3. Пройдите онбординг, затем попробуйте чат, загрузку фото, демонстрационный анализ, исправление анализа, прогресс и профиль.

## Что уже работает в прототипе
- Переходы между экранами.
- Онбординг: рост, вес, пол, измерения, цель.
- Профиль и редактирование данных.
- Загрузка и предпросмотр фото на клиенте.
- Демонстрационная карточка анализа еды.
- Поток исправления распознавания через ввод уточнения.
- Учёт демо-записей и обновление простых показателей прогресса.

## Что пока НЕ подключено
- Telegram WebApp SDK и проверка Telegram initData на сервере.
- Backend/API и база данных: данные хранятся только в памяти вкладки и сбрасываются после перезагрузки.
- Реальная модель AI: результат анализа пока демонстрационный; фото не отправляются на сервер.
- Реальные push/Telegram-уведомления, расписание и отчёты.
- Постоянное хранилище изображений и пользовательских записей.

## Следующий этап разработки
