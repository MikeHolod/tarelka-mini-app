# Тарелка — с чего начать запуск

## Что уже есть
- `index.html` — интерактивный интерфейс-прототип.
- `backend/` — начальный FastAPI backend, проверка Telegram Mini App initData и черновик схемы PostgreSQL.

## Что ещё не подключено
- Постоянное сохранение профилей и еды в БД.
- Реальная обработка фотографий AI.
- Telegram-бот и расписание уведомлений.
- Публичный production-деплой.

## Рекомендованный старт без VPS
1. Создать Telegram-бота через [@BotFather](https://t.me/BotFather) и сохранить токен приватно.
2. Создать проект в [Supabase](https://supabase.com/) для PostgreSQL и объектного хранения. Бесплатный тариф подходит для прототипа, но имеет лимиты и проекты могут приостанавливаться после неактивности. Перед хранением личных данных проверить актуальные условия.
3. Разместить frontend как статический сайт. Например, Render предлагает бесплатные static sites; Vercel Hobby бесплатен для личных проектов, но ограничен условиями использования.
4. Разместить FastAPI backend на хостинге, поддерживающем Python. Бесплатные инстансы могут засыпать, а бесплатная БД Render имеет ограниченный срок жизни — не использовать её как единственное хранилище долгосрочных данных.
5. После получения URL frontend указать его в настройках Mini App у Telegram-бота.
6. Добавить секреты через панель хостинга, а не в HTML/JS и не в Git.
